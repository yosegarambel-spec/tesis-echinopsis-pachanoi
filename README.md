# Repositorio de tesis

Repositorio de control de versiones y respaldo documental.

## Estado de seguridad
**No subir borradores, datos experimentales, observaciones de jurado ni documentos fuente mientras el repositorio sea público.**

Antes de incorporar el expediente académico completo, cambiar la visibilidad del repositorio a **Private**.

## Estructura prevista
- `source/`: versiones fuente entregadas.
- `docs/`: estado consolidado, decisiones metodológicas y observaciones.
- `checklists/`: anexos y controles pendientes.
- `CHANGELOG.md`: historial de cambios.

## Regla de integridad
No inventar, completar ni reconstruir datos experimentales faltantes. Toda modificación debe conservar trazabilidad con el borrador presentado y los registros experimentales originales.
